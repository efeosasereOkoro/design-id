# ✦ Icebreaker ID

A mobile-first web app for generating fun team identity cards — perfect for delivery teams and workshops.

**Live site:** https://efeosasereokoro.github.io/design-id/

## Features
- Enter your name and role to generate a unique identity card
- A–Z trait dictionary with 10 words per letter
- 20+ role-to-identity mappings for delivery & public sector teams
- Download as 1080×1080px Instagram-ready PNG
- Native share support
- Regenerate to shuffle your identity

## Tech
Built with React + Vite. Deployed via GitHub Pages.
